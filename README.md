# CoC AutoAttack

Android-приложение, которое само фармит в Clash of Clans: атакует по кругу, высаживает всю армию вдоль границы карты, возвращается домой и тратит ресурсы на улучшения через меню строителей, чтобы хранилища не переполнялись.

Настраивать ничего не нужно. Кнопки игры уже вшиты в приложение, карточки войск бот находит на панели сам, края высадки считает по границе карты.

Работает без root: экран читается через MediaProjection, нажатия делает служба доступности, кнопки ищутся по картинкам-шаблонам (OpenCV).

> ⚠️ Боты запрещены правилами Supercell. Аккаунт могут заблокировать, Supercell может потребовать удалить этот репозиторий. Используйте на свой риск.

## Запуск

1. Установите APK. Система спросит про установку из неизвестных источников, разрешите.
2. Откройте приложение и разрешите уведомления. В уведомлении видна статистика и кнопка «Стоп».
3. **Служба доступности.** Кнопка на главном экране откроет системные настройки, включите «CoC AutoAttack (тапы)».
4. **Поверх окон.** Вторая кнопка, включите переключатель. Нужна для строки статуса поверх игры.
5. **Батарея без ограничений.** Настройки телефона, Приложения, CoC AutoAttack, Батарея, «Без ограничений». На Xiaomi, Huawei и Samsung ещё снимите автозакрытие в фоне.
6. **Экран не должен гаснуть.** Поставьте тайм-аут экрана 10 минут или больше.
7. Нажмите **«Запустить»** и в окне захвата выберите **«Весь экран»**, а не одно приложение. Игра откроется сама, через 5 секунд бот начнёт.

Остановить: «Стоп» в приложении, в уведомлении или тап по строке статуса поверх игры.

Первый раз поставьте в настройках «Сколько атак» равным 1 и посмотрите, как пройдёт бой.

## Что бот делает сам

```
своя база
  ├─ прокачка: значок строителей → «Можно улучшить» → «Улучшить» → «Подтвердить»
  └─ атака
       ├─ «В бой!» → «Подбор» обычного сражения → «Моя армия», «В бой!»
       ├─ чужая база: находит карточки войск на панели
       ├─ высадка: каждая карточка по всем четырём краям карты, потом способности героев
       ├─ ждёт итогов «Домой» (сдаётся через 200 с, если бой не кончился сам)
       └─ домой, пауза, следующий круг
```

## Безопасность

- Окна бот закрывает **только красным крестиком**. Зелёные кнопки нажимаются лишь названные: «В бой!», «Домой», «Подтвердить» в окне улучшения и «ОК» в подтверждении сдачи.
- В окне «Не хватает ресурсов» игра предлагает докупить их за кристаллы. Бот узнаёт это окно по заголовку и закрывает крестиком.
- Прокачка начинается, только если в меню строителей есть «Свободен!». Иначе игра предложила бы ускорить стройку за кристаллы.
- Из двух кнопок «Подбор» бот берёт левую, обычное сражение. Правая, ранговая, не нажимается.
- Кнопка «ОК» из окна «Прекратить улучшение?» бот не трогает: «ОК» ищется только во время сдачи в бою.

## Прокачка

Бот открывает меню у значка строителей и пробует строки из «Можно улучшить» сверху вниз. Если на строку не хватает ресурсов, он переходит к следующей. После трёх отказов подряд прокачка до следующей атаки прекращается.

В этом списке бывают и герои. Улучшение героя выводит его из боя на время стройки. Если это не подходит, выключите авто-прокачку или отметьте цели вручную: **Настройки → Цели прокачки**. Тогда бот улучшает только отмеченные здания.

## Шаблоны атак

По умолчанию стоит **«Всё войско по кругу»**. Он не знает состава армии и не должен знать: бот сам находит карточки на панели, берёт каждую по очереди и раскладывает по краям карты, а через 12 секунд проходит по карточкам ещё раз, чтобы включить способности героев. Заклинания в этом шаблоне тоже бросаются по краям, для фармовой армии это неважно.

Остальные шаблоны можно выбрать или собрать свои в **«Шаблоны атак»**. Шаг высадки пишется строкой `карточка:количество:края[:пауза_мс]`, например `1:40:1,2,3,4:500`.

## Ограничения

- **Язык игры.** На кнопках надписи, встроенный набор снят с русской версии. Для английской нужен свой набор.
- **Обновления игры** иногда меняют кнопки. Тогда набор пересобирается скриптом ниже.
- **Другие телефоны.** Поиск идёт в едином масштабе, поэтому разрешение не важно. Пропорции экрана проверены на 20:9, на заметно других края высадки могут потребовать правки.
- **Фильтр добычи, сбор ресурсов и тренировка** требуют своих вырезок, во встроенный набор они пока не входят и по умолчанию выключены.
- Если игра покажет незнакомое окно без крестика, бот его не закроет и через несколько попыток перезапустит игру.

## Свои вырезки кнопок

Если какая-то кнопка у вас не узнаётся, её можно вырезать прямо в телефоне: **«Шаблоны кнопок»**, строка кнопки, «Вырезать». Своя вырезка важнее встроенной. «Проверка» на главном экране пишет в лог похожесть каждого шаблона на текущем экране.

## Для разработчика

Встроенный набор лежит в `app/src/main/assets/templates`. Все шаблоны хранятся в рабочем масштабе: кадр высотой 540 пикселей. У шаблона может быть несколько вариантов, например `close.png`, `close~2.png`: засчитывается лучший.

Как пересобрать набор:

1. Сложите полные скриншоты игры в `raw/screens`. Папка `raw` в `.gitignore`: на снимках ник и клан.
2. Приведите их к высоте 540 в `raw/norm` и опишите вырезки в `tools/pack_spec.json`.
3. Соберите и проверьте:

```bash
python tools/make_pack.py --check
```

Скрипт вырезает шаблоны и печатает таблицу: похожесть каждого шаблона на каждом снимке. У кнопки звёздочка должна стоять только на экранах, где она есть.

Сборка: Android Studio Koala или новее, либо GitHub Actions, workflow `Build APK`. Юнит-тесты: `./gradlew testDebugUnitTest`. Среди них проверка поиска карточек на настоящих кадрах боя: в тестовых файлах лежит только нижняя полоса экрана.

## Структура

```
app/src/main/java/com/kotbaton/cocbot/
  BotEngine.kt               логика: база, прокачка, поиск, высадка, бой
  Vision.kt                  поиск шаблонов OpenCV в едином масштабе, варианты шаблонов
  TroopBar.kt                поиск карточек войск на панели боя
  AttackPreset.kt            шаблоны атак, края по границе карты
  BotService.kt              foreground-служба: MediaProjection + сценарии
  BotAccessibilityService.kt тапы через dispatchGesture
  ScreenCapturer.kt          кадры экрана в Bitmap
  MainActivity.kt            запуск, выбор шаблона, статус и лог
  SettingsActivity.kt        общие настройки, цели прокачки
  TemplatesActivity.kt       список шаблонов, вырезание, выгрузка архивом
  TemplateCutterActivity.kt  вырезание кнопки из снимка прямо в телефоне
  PresetsActivity.kt         список шаблонов атак
  PresetEditorActivity.kt    редактор шаблона атаки
  PointPickerActivity.kt     выбор точек по скриншоту
  LootReader.kt              чтение чисел добычи шаблонами цифр
  BotConfig.kt, BotStats.kt, BotState.kt, Geometry.kt, OverlayController.kt
app/src/main/assets/templates/  встроенный набор кнопок
tools/make_pack.py              сборка и проверка набора
app/src/test/                   юнит-тесты
```
