# CoC AutoAttack

Android-приложение, которое само фармит в Clash of Clans: атакует по кругу, высаживает всю армию вдоль границы карты, возвращается домой улучшает стены через меню строителей и останавливается, когда хранилища заполнены.

Настраивать ничего не нужно. Кнопки игры уже вшиты в приложение, карточки войск бот находит на панели сам, края высадки считает по границе карты.

Работает без root: экран читается через MediaProjection, нажатия делает служба доступности, кнопки ищутся по картинкам-шаблонам (OpenCV).

> ⚠️ Боты запрещены правилами Supercell. Аккаунт могут заблокировать, Supercell может потребовать удалить этот репозиторий. Используйте на свой риск.

## Запуск

1. Установите APK. Система спросит про установку из неизвестных источников, разрешите.
2. Откройте приложение и разрешите уведомления. В уведомлении видна статистика и кнопка «Стоп».
3. **Служба доступности.** В списке «Перед запуском» на главном экране нажмите «Включить»: откроются системные настройки, включите «CoC AutoAttack (тапы)».
4. **Поверх окон.** Там же нажмите «Разрешить» и включите переключатель. Нужна для строки статуса поверх игры. Когда всё готово, строки списка зелёные.
5. **Батарея без ограничений.** Настройки телефона, Приложения, CoC AutoAttack, Батарея, «Без ограничений». На Xiaomi, Huawei и Samsung ещё снимите автозакрытие в фоне.
6. **Экран не должен гаснуть.** Поставьте тайм-аут экрана 10 минут или больше.
7. Выберите режим над кнопкой запуска: «N атак» (число задаётся в настройках) или «До полных хранилищ». Нажмите **«Запустить»** и в окне захвата выберите **«Весь экран»**, а не одно приложение. Игра откроется сама, через 5 секунд бот начнёт.

Остановить: «Стоп» в приложении или в уведомлении. Плашка статуса в левом верхнем углу нужна только для информации, касания она не ловит.

Первый раз поставьте в настройках «Сколько атак» равным 1 и посмотрите, как пройдёт бой.

## Что бот делает сам

```
своя база
  ├─ сбор: тап по пузырям золота, эликсира и чёрного эликсира над шахтами
  ├─ стены: значок строителей → строка «Стена» (список листается) → «Улучшить» → «Подтвердить»
  └─ атака
       ├─ «В бой!» → «Подбор» обычного сражения → «Моя армия», «В бой!»
       ├─ чужая база: находит карточки войск на панели
       ├─ высадка: каждая карточка по всем четырём краям карты, потом способности героев
       ├─ ждёт итогов «Домой» (сдаётся через 200 с, если бой не кончился сам)
       └─ домой, пауза, следующий круг
```

## Фильтр добычи

Настройки → «Фильтр добычи». Бот читает «Доступную добычу» на экране чужой базы (золото, эликсир, чёрный эликсир) и жмёт «Далее», пока добыча ниже ваших порогов, но не больше заданного числа раз. Ничего размечать не нужно. Каждое «Далее» стоит золота, поэтому по умолчанию фильтр выключен. Число, которое не удалось прочитать, базу не отбрасывает.

## Плохая связь

Если игра не загрузилась и показала «Ошибка подключения» или «Не удалось войти», бот сам нажимает «Попробуйте снова» и ждёт загрузки. Если за 10 нажатий игра не дошла до базы, бот закрывает её (кнопка «Домой», затем завершение процесса) и останавливается. Так же бот закрывает «Подключение прервано». Проверка идёт на каждом шаге, в том числе при старте, сборе и во время боя.

## Звёздный бонус

После боя, если выпал звёздный бонус, бот нажимает «ОК» в этом окне. Кнопка нажимается только вместе с заголовком «Получен звёздный бонус!», зелёные «ОК» из других окон бот не трогает.

## Безопасность

- Окна бот закрывает **только красным крестиком**. Зелёные кнопки нажимаются лишь названные: «В бой!», «Домой», «Подтвердить» в окне улучшения и «ОК» в подтверждении сдачи.
- В окне «Не хватает ресурсов» игра предлагает докупить их за кристаллы. Бот узнаёт это окно по заголовку и закрывает крестиком.
- Улучшаются только стены, другие здания и герои бот не трогает. Если стену улучшить не удалось три раза подряд, прокачка отключается до конца запуска.
- Из двух кнопок «Подбор» бот берёт левую, обычное сражение. Правая, ранговая, не нажимается.
- Кнопка «ОК» из окна «Прекратить улучшение?» бот не трогает: «ОК» ищется только во время сдачи в бою.

## Стены и остановка по хранилищам

**Стены.** Сначала проверяется счётчик строителей сверху: при «0/…» стены не улучшаются, этап пропускается. Затем бот нажимает значок строителей (правый из двух, там «1/7» или «0/7»), ищет в списке строку «Стена» и листает список вниз, пока не найдёт. Внизу для стены две кнопки «Улучшить»: за золото и за эликсир. Бот берёт тот ресурс, чьё хранилище полнее, а если не хватило, второй. Дальше «Подтвердить». Стены улучшаются подряд, пока хватает ресурсов. Ресурсов не хватило: бот продолжает фарм и пробует снова через несколько атак. Строки «Стена» нет во всём списке: бот пишет «Все стены прокачаны» и больше не открывает список.

**Остановка.** Когда стены закончились (или прокачка выключена), бот фармит дальше и останавливается, как только хранилища заполнены. Полоса ресурса справа вверху заполнена не меньше чем на 97%. По умолчанию ждём золото и эликсир, чёрный эликсир копится медленно и отключён. Настройки → «Остановка по хранилищам». В логе перед каждой атакой пишется заполнение: «Хранилища: золото 87%, эликсир 88%…».

**Фарм до максимума.** Режим «До полных хранилищ» над кнопкой «Запустить»: бот только атакует, ничего не улучшает, не ограничен числом атак и останавливается, когда хранилища заполнены. Предохранитель: не больше 2000 атак за запуск.

## Шаблоны атак

По умолчанию стоит **«Всё войско по кругу»**. Он не знает состава армии и не должен знать: бот сам находит карточки на панели, берёт каждую по очереди и раскладывает по краям карты, а через 12 секунд проходит по карточкам ещё раз, чтобы включить способности героев. Заклинания в этом шаблоне тоже бросаются по краям, для фармовой армии это неважно.

Остальные шаблоны можно выбрать или собрать свои: карточка «Шаблон атаки» на главном экране открывает список, тап по строке делает шаблон активным. В редакторе шаги высадки добавляются формой: карточка, число тапов, края и пауза после шага. В файле шаблона шаг хранится строкой `карточка:количество:края[:пауза_мс]`, например `1:40:1,2,3,4:500`.

## Ограничения

- **Язык игры.** На кнопках надписи, встроенный набор снят с русской версии. Для английской нужен свой набор.
- **Обновления игры** иногда меняют кнопки. Тогда набор пересобирается скриптом ниже.
- **Другие телефоны.** Поиск идёт в едином масштабе, поэтому разрешение не важно. Пропорции экрана проверены на 20:9, на заметно других края высадки могут потребовать правки.
- Если игра покажет незнакомое окно без крестика, бот его не закроет и через несколько попыток перезапустит игру.

## Свои вырезки кнопок

Если какая-то кнопка у вас не узнаётся, её можно вырезать прямо в телефоне: **«Шаблоны кнопок»**, меню «⋮» в строке кнопки, «Вырезать из снимка». Своя вырезка важнее встроенной. «Проверка» на главном экране пишет в лог похожесть каждого шаблона на текущем экране.

## Для разработчика

Встроенный набор лежит в `app/src/main/assets/templates`. Все шаблоны хранятся в рабочем масштабе: кадр высотой 540 пикселей. У шаблона может быть несколько вариантов, например `close.png`, `close~2.png`: засчитывается лучший.

Как пересобрать набор:

1. Сложите полные скриншоты игры в `raw/screens`. Папка `raw` в `.gitignore`: на снимках ник и клан.
2. Приведите их к высоте 540 в `raw/norm` и опишите вырезки в `tools/pack_spec.json`.
3. Соберите и проверьте:

```bash
python tools/make_pack.py --check
```

Скрипт вырезает шаблоны и печатает таблицу: похожесть каждого шаблона на каждом снимке. У кнопки звёздочка должна стоять только на экранах, где она есть.

Сборка: Android Studio Koala или новее, либо GitHub Actions, workflow `Build APK`. Юнит-тесты: `./gradlew testDebugUnitTest`. Среди них проверка поиска карточек на настоящих кадрах боя: в тестовых файлах лежит только нижняя полоса экрана.

## Структура

```
app/src/main/java/com/kotbaton/cocbot/
  BotEngine.kt               логика: база, прокачка, поиск, высадка, бой
  Vision.kt                  поиск шаблонов OpenCV в едином масштабе, варианты шаблонов
  TroopBar.kt                поиск карточек войск на панели боя
  StorageBars.kt             заполнение хранилищ по полосам ресурсов, без OpenCV
  AttackPreset.kt            шаблоны атак, края по границе карты
  BotService.kt              foreground-служба: MediaProjection + сценарии
  BotAccessibilityService.kt тапы через dispatchGesture
  ScreenCapturer.kt          кадры экрана в Bitmap
  MainActivity.kt            запуск, выбор шаблона, статус и лог
  SettingsActivity.kt        общие настройки
  TemplatesActivity.kt       список шаблонов, вырезание, выгрузка архивом
  TemplateCutterActivity.kt  вырезание кнопки из снимка прямо в телефоне
  PresetsActivity.kt         список шаблонов атак
  PresetEditorActivity.kt    редактор шаблона атаки
  PointPickerActivity.kt     выбор точек по скриншоту
  LootReader.kt, LootDigits.kt  чтение добычи с экрана чужой базы, без OpenCV
  LootDigitData.kt           образцы цифр (генерируется tools/make_digit_protos.py)
  BotConfig.kt, BotStats.kt, BotState.kt, Geometry.kt, OverlayController.kt
app/src/main/assets/templates/  встроенный набор кнопок
tools/make_pack.py              сборка и проверка набора кнопок
tools/make_digit_protos.py      образцы цифр добычи и фрагменты кадров для тестов
app/src/test/                   юнит-тесты
```
