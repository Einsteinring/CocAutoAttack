# Журнал версий

Версия пишется в `app/build.gradle.kts`: `versionName` для людей, `versionCode` растёт на единицу с каждым релизом. Каждая версия попадает сюда, получает тег `vX.Y` и релиз на GitHub с APK.

## 0.1

Первый рабочий выпуск. Проверен на живой игре: 5 атак подряд без ошибок.

- Кнопки игры (русская версия) вшиты в приложение, ручная настройка не нужна.
- Карточки войск находятся на панели боя автоматически.
- Края высадки считаются по границе карты.
- Шаблон атаки «Всё войско по кругу»: каждая карточка по всем четырём краям, затем способности героев.
- Прокачка через меню строителей, только когда есть свободный строитель.
- Окна закрываются только красным крестиком, кристаллы бот не тратит.
- Шаблоны атак, редактор, вырезание своих кнопок прямо в телефоне, выгрузка снимков архивом.

Не входит: сбор ресурсов, тренировка армии и фильтр добычи (нужны свои вырезки, по умолчанию выключены).
